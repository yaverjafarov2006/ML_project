# Presentation

ML_Final_Slides.pdf is the submission PDF. ML_Final_Slides.pptx contains editable
text, native tables and charts with embedded data workbooks. It has 11 slides
and Azerbaijani presenter notes. Add the real team names to the cover before
submission. See DEFENSE_GUIDE_AZ.md for the demo and likely questions.

deck_data.json contains the measured numerical inputs. build_slides.mjs is the
authoring source for the Artifact Tool runtime; ordinary users can edit the
PPTX in PowerPoint/LibreOffice and export to PDF. No paid AI API or API key is
needed to run the machine-learning project.
